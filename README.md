# 💸 SplitSmart – Smart Group Expense Manager

SplitSmart is a simple and intuitive expense-splitting application designed to help students and groups manage shared expenses effortlessly. Whether it's hostel expenses, group outings, trips, or shared meals, SplitSmart makes tracking expenses and settling balances easier.

## ✨ Features

- 📊 **Dashboard** – View total expenses, contributions, balances and recent transactions.
- 👥 **Group Management** – Create groups and manage shared expenses.
- 💰 **Expense Tracking** – Add, edit and delete group expenses.
- ⚖️ **Flexible Splitting** – Split expenses equally, unequally or by percentage.
- 🧮 **Balance Calculation** – Automatically calculate who owes whom.
- 🔄 **Settlement Suggestions** – Get simplified suggestions to settle outstanding balances.
- 📈 **Spending Insights** – View expense breakdowns and spending trends.
- 📁 **CSV Export** – Export expense records.
- 🌙 **Dark Mode** – Switch between light and dark themes.

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Browser LocalStorage

## 🚀 Getting Started

Clone the repository:

```
git clone https://github.com/agrimatiwari/SplitSmart.git
```

Navigate to the project folder:

```
cd SplitSmart
```

Open `index.html` in your browser or use the **Live Server** extension in VS Code to run the application.

No additional installation is required.

## 💾 Data Storage

SplitSmart uses browser LocalStorage to save groups, expenses and user preferences. Data remains available in the same browser but is not synchronised across different devices or users.

## 🎯 Purpose

SplitSmart aims to make group expense management more organised, transparent and convenient by simplifying the process of tracking shared expenses and calculating balances.
